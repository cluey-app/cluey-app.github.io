자주 묻는 질문

없는 질문은 kyg6135@naver.com 으로 보내 주세요.

설치 · 시작

설치할 때 "Windows의 PC 보호" 창이 떠요.

추가 정보 → 실행 을 누르세요. 개인이 만든 무료 프로그램이라 코드 서명 인증서가 없어서 윈도우가 확인을 한 번 더 받습니다.

"애플리케이션 제어 정책에서 이 파일을 차단했습니다" 가 떠요.

Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 을 끄기 로 바꾼 뒤 다시 실행하세요.

스마트 앱 컨트롤은 한 번 끄면 윈도우를 새로 설치하기 전에는 다시 켤 수 없습니다. 괜찮을 때만 끄세요.

어느 윈도우에서 되나요?

Windows 10 과 11 입니다. 맥과 휴대폰용은 없습니다.

무료인가요? 광고가 있나요?

모든 기능이 무료이고 광고는 없습니다. 이용약관과 개인정보처리방침에 같은 내용이 적혀 있습니다.

인터넷이 없어도 쓸 수 있나요?

네. 켜고, 쓰고, 저장하고, 검색하는 것은 모두 인터넷 없이 됩니다. 로그인해서 동기화를 쓰는 경우에도 끊겨 있는 동안은 이 PC 에서 그대로 쓰고, 연결되면 저절로 맞춥니다. 친구, 메모 보내기, 공유 폴더처럼 서버가 필요한 기능만 연결되어 있어야 합니다.

업데이트

새 버전은 어떻게 받나요?

켤 때와 하루에 한 번 새 버전이 있는지 확인하고, 있으면 받아 둡니다. 맨 위에 업데이트 단추가 나타나고, 누르거나 Cluey 를 끌 때 설치됩니다. 설정의 업데이트 칸에서 자동 확인을 끄고 켤 수 있습니다.

업데이트하면 메모가 지워지나요?

아니요. 메모는 프로그램과 따로 저장되어 있어 업데이트와 상관없이 그대로입니다.

로그인 · 동기화

로그인을 꼭 해야 하나요?

아니요. 로그인하지 않아도 PC 안의 기능은 모두 쓸 수 있습니다. 여러 PC 동기화, 친구, 메모 보내기, 공유 폴더, API 키만 로그인이 필요하고, 로그인은 구글 계정으로 합니다.

구글로 로그인하면 "계정을 연결하는 중" 에서 멈춰요.

1.2.0 에서 있던 문제로 1.2.1 에서 고쳤습니다. 새 버전으로 업데이트하세요.

두 PC 에서 같은 메모를 동시에 고치면요?

나중에 고친 쪽이 남고, 다른 쪽은 "충돌 사본" 메모로 남습니다. 아무것도 사라지지 않으니 두 메모를 보고 합치면 됩니다. 동기화 설명

동기화에 용량 한도가 있나요?

한 사람당 1GB 이고, 메모 하나(그림 포함)는 25MB 까지입니다. 25MB 를 넘는 메모는 올리지 않고 건너뜁니다. 건너뛴 메모가 있으면 알려 줍니다.

잃어버린 PC 에서 로그인을 끊고 싶어요.

다른 PC 에서 설정 > 계정의 다른 PC 로그아웃 을 누르면 지금 PC 만 남기고 모든 PC 의 로그인이 끊깁니다. 쓰지 않은 PC 는 90일 뒤 저절로 끊깁니다.

구글 드라이브로 맞추던 메모는 어떻게 되나요?

서버로 처음 맞출 때 자동으로 옮겨집니다. 한 번만 하고, 중간에 끊겨도 이어서 합니다. 드라이브의 파일은 읽기만 하고 지우지 않습니다. 옮긴 지 30일이 지나면 예전 사본을 지울 수 있다는 안내 카드가 뜨고, 지우지 않아도 문제는 없습니다.

메모 잠금

잠금 비밀번호를 잊었어요.

찾을 수 없습니다. 그 메모는 아무도 열 수 없고, Cluey 운영자도 마찬가지입니다. 볼 수 있는 것은 잠글 때 적어 둔 힌트 뿐입니다. 그래서 잠글 때 비밀번호를 따로 적어 두기를 권합니다.

잠근 메모는 서버에서도 안전한가요?

암호화된 채로 서버에 올라가서 운영자도 읽을 수 없습니다. 제목은 목록과 검색을 위해 그대로 보입니다. 메모 잠금 설명

공유 · AI 연결

친구에게 폴더를 나눠 주려면요?

로그인한 상태에서 폴더를 오른쪽 클릭하고 공유… 를 고릅니다. 받는 사람이 받기 를 눌러야 목록에 생깁니다. 잠근 메모는 공유 폴더에 넣을 수 없습니다. 공유 폴더 설명

AI 연결을 했는데 Claude 에서 Cluey 가 안 보여요.

Claude 데스크톱은 창을 닫는 것으로는 부족하고 완전히 끝냈다가 다시 켜야 합니다(시계 옆 아이콘에서 끝내기). Claude Code 와 Codex 는 다시 시작하면 됩니다. 접속 키를 다시 만든 뒤라면 Cluey 설정 > AI 연결에서 다시 연결 을 누르세요. AI 도구 연결 설명

웹의 Claude 나 ChatGPT 에도 연결할 수 있나요?

지금은 안 됩니다. AI 연결은 내 PC 안에서 실행되는 도구(Claude 데스크톱, Claude Code, Codex 등)만 쓸 수 있습니다. 프로그램을 직접 만들 수 있다면 API 키로 서버의 메모를 가져갈 수 있습니다.

AI 가 내 메모를 고치거나 지울 수 있나요?

아니요. 찾기, 읽기, 새 메모 쓰기만 됩니다. 잠긴 메모와 "AI에게 숨기기" 한 폴더는 보이지 않습니다.

탈퇴 · 자료 삭제

탈퇴하면 자료가 바로 지워지나요?

설정 > 계정에서 탈퇴하면 모든 PC 의 로그인이 끊기고 30일 동안 보관합니다. 그 안에 다시 로그인하면 되살아납니다. 30일이 지나면 이름, 닉네임, 이메일, 친구 목록, 서버에 맞춰 둔 메모와 그림, API 키 같은 서버의 자료를 모두 지웁니다. 내 PC 의 메모는 지워지지 않습니다. 자세한 내용은 개인정보처리방침에 있습니다.

공유 폴더의 주인이 탈퇴하면요?

탈퇴 전에 다른 사람에게 주인을 넘길지 묻습니다. 넘기지 않으면 30일 보관 기간 뒤 그 폴더와 안의 메모가 지워지니, 함께 쓰던 사람은 필요한 내용을 미리 자기 폴더로 옮겨 두세요.

생각이 막힐 땐, 클루이를 켜세요.
