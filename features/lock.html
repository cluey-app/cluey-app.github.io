메모 잠금

메모마다 비밀번호를 걸어 암호화합니다. 운영자도 열 수 없습니다.

메모마다 비밀번호를 겁니다

  1. 잠글 메모의 위쪽 ⋯ 메뉴나 목록의 오른쪽 클릭 메뉴에서 잠그기 를 고릅니다.
  2. 비밀번호(4자 이상)를 두 번 넣습니다. 힌트는 적어도 되고 안 적어도 됩니다.
  3. 창에 적힌 안내를 읽고 잠급니다. 목록에 자물쇠 표시가 생깁니다.

진짜 암호화입니다

본문, 장소, 프로젝트, 참석자는 비밀번호로 암호화되어 저장되고 원래 칸은 비워집니다. 제목은 목록과 검색에 쓰려고 그대로 보입니다. 로그인해서 동기화를 쓰는 경우에도 잠긴 메모는 암호화된 채로 서버에 올라가서, Cluey 운영자도 읽을 수 없습니다.

열고 닫기

  • 잠긴 메모를 열면 본문 자리에 비밀번호 입력 칸과 힌트 보기 가 나옵니다. 맞으면 열려서 고칠 수 있고, 저장할 때 다시 암호화됩니다.
  • 다른 메모로 옮기거나 창을 닫으면 다시 잠깁니다.
  • 열려 있을 때 ⋯ 메뉴에서 잠금 풀기(암호화 없앰)와 비밀번호 바꾸기 를 할 수 있습니다.

비밀번호를 잊으면 그 메모는 아무도 열 수 없습니다. 찾아 드릴 방법이 없고, 힌트만 볼 수 있습니다. 중요한 메모는 비밀번호를 따로 적어 두세요.

잠긴 동안 달라지는 것

  • 본문 검색, 할 일 모아보기, 폴더 모아보기에서 빠집니다.
  • 스티커로 띄우거나 복제할 수 없고, 공유 폴더에도 넣을 수 없습니다("잠금을 풀고 넣어 주세요").
  • AI 도구 연결과 API 키에는 어떤 경우에도 보이지 않습니다.
  • 복사, 출력, 내보내기는 열려 있을 때만 됩니다.
  • 백업에는 암호화된 채로 들어갑니다.
