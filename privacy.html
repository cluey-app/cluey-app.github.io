개인정보처리방침

시행일 2026년 10월 8일

요약 — Cluey 에는 서버가 없습니다. 메모는 여러분의 PC 와, 동기화를 켠 경우 여러분 본인의 구글 드라이브 안 Cluey 전용 숨은 칸에만 저장됩니다. Cluey 를 만든 사람은 여러분의 메모나 개인정보를 받거나 볼 수 없습니다.

1. Cluey 가 다루는 정보

정보어디에왜
메모·폴더·양식·자주 쓰는 장소·설정내 PC (문서\Cluey 폴더)프로그램이 동작하려면 필요합니다
위와 같은 메모 자료 (동기화를 켠 경우)내 구글 드라이브의 앱 전용 숨은 칸 (appDataFolder)같은 구글 계정으로 로그인한 내 PC 들끼리 메모를 맞추려고
구글 계정 이메일 주소내 PC (암호화)설정 화면에 어느 계정으로 로그인했는지 보여 주려고
구글 로그인 정보 (토큰)내 PC (윈도우 DPAPI 로 암호화)동기화할 때마다 다시 로그인하지 않으려고
이 PC 이름내 PC, 동기화한 메모 자료두 PC 에서 같은 메모를 고쳤을 때 "충돌 사본" 에 어느 PC 것인지 적으려고

Cluey 는 이 밖의 정보(사용 기록, 위치, 연락처, 기기 식별자 등)를 모으지 않고, 광고나 분석 도구를 쓰지 않습니다.

2. 구글 계정 정보를 쓰는 방법

동기화는 고를 수 있는 기능이며, 켜려면 구글 계정으로 로그인합니다. Cluey 가 요청하는 권한은 다음뿐입니다.

  • https://www.googleapis.com/auth/drive.appdata — 구글 드라이브 안 Cluey 전용 숨은 칸의 파일만 만들고, 읽고, 고치고, 지웁니다. 드라이브의 다른 파일과 폴더는 볼 수 없습니다.
  • openid, email — 로그인한 계정의 이메일 주소를 설정 화면에 보여 주는 데만 씁니다.

구글에서 받은 정보는 여러분의 PC 와 여러분의 구글 드라이브 사이에서만 오가며, Cluey 개발자를 포함한 누구에게도 보내지 않습니다. 팔거나 광고에 쓰거나 사람이 읽지 않습니다.

Cluey 가 Google API 에서 받은 정보를 사용하고 다른 곳으로 옮기는 것은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 포함해 그 정책을 따릅니다.

3. 잠근 메모

비밀번호로 잠근 메모는 내 PC 에서 암호화(AES-GCM)되어 저장되고, 동기화할 때도 암호화된 채로 구글 드라이브에 올라갑니다. 비밀번호는 어디에도 저장하지 않으므로, 잊으면 개발자도 메모를 열 수 없습니다.

4. 보관 기간과 지우는 방법

  • 내 PC: 메모는 지울 때까지 남습니다. 프로그램을 지운 뒤 문서\Cluey 폴더를 지우면 모두 사라집니다.
  • 로그인 정보: Cluey 의 설정 → 동기화 → 로그아웃 을 누르면 PC 에서 지우고 구글에도 권한을 돌려줍니다. 구글 계정의 서드 파티 앱 및 서비스에서 Cluey 를 지워도 됩니다.
  • 구글 드라이브의 메모 자료: 구글 드라이브 웹 → 설정 → 앱 관리 → Cluey → 숨겨진 앱 데이터 삭제 로 모두 지울 수 있습니다.

5. 다른 곳에 주거나 맡기기

Cluey 는 개인정보를 다른 사람이나 회사에 주지 않고, 처리를 맡기지도 않습니다. 동기화한 자료는 여러분이 구글과 맺은 약관에 따라 구글 드라이브에 보관됩니다.

6. 어린이

Cluey 는 만 14세 미만 어린이를 대상으로 하지 않으며, 어린이의 정보를 따로 모으지 않습니다.

Summary in English

Cluey is an offline note-taking app for Windows. It has no server. Notes are stored on the user's PC and, only if the user turns on sync, in the hidden application data folder (appDataFolder) of the user's own Google Drive.

Cluey requests the drive.appdata scope to create, read, update and delete its own files in that folder, and openid/email to show which account is signed in. It cannot see any other Drive files. Google user data is transferred only between the user's PC and the user's own Google Drive; it is never sent to the developer or any third party, never sold, never used for advertising, and never read by humans. Refresh tokens are stored on the PC encrypted with Windows DPAPI. Password-locked notes are uploaded encrypted.

Cluey's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Users can sign out in Settings → Sync (which revokes the token), remove Cluey at myaccount.google.com/permissions, and delete Cluey's hidden app data from Google Drive settings → Manage apps. Contact: kyg6135@naver.com.
