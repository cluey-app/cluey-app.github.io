요약 - 메모는 여러분의 PC 에 저장됩니다. 로그인하면 같은 메모가 Cluey 서버(Cloudflare)에도 보관되어 여러 PC 에서 이어 쓰고 친구와 주고받을 수 있습니다. 서버에 올라간 메모는 그 기능을 하려고 서비스가 읽을 수 있는 상태이며, 운영자는 문의, 보안 사고나 신고, 법적 요청이 있을 때만 열어 볼 수 있고 열 때마다 기록을 남깁니다. 비밀번호로 잠근 메모는 서버에도 잠긴 채로 올라가 운영자도 볼 수 없습니다. 로그인하지 않으면 서버에 아무것도 보내지 않습니다.

2. 구글 계정 정보를 쓰는 방법

로그인은 구글 계정으로만 하며, Cluey 가 요청하는 권한은 다음뿐입니다.

  • openid, email, profile: 로그인한 계정의 이메일 주소와 이름을 확인해서 계정을 만들고, 설정 화면에 보여 주고, 메모 보내기와 친구 기능에서 사람을 알아보는 데 씁니다. 구글의 다른 정보는 받지 않습니다.

구글 드라이브 권한은 더 요청하지 않습니다. 예전 버전에서 드라이브로 동기화하며 이미 드라이브 권한을 허락한 분은, 서버에 처음 로그인할 때 그 권한으로 Cluey 전용 숨은 칸의 메모 자료를 한 번 읽어 서버로 옮깁니다. 이때 드라이브의 파일은 읽기만 하고 지우거나 고치지 않으며, 드라이브에 있는 사본은 그대로 남습니다. 옮긴 뒤로는 드라이브를 쓰지 않으며, 남은 사본은 구글 드라이브 웹의 설정, 앱 관리, Cluey, 숨겨진 앱 데이터 삭제로 직접 지울 수 있습니다.

구글에서 받은 정보를 그 밖의 용도로 쓰거나 팔거나 광고에 쓰지 않습니다. 운영자가 이름이나 이메일을 보는 것은 아래 3번의 열람 원칙에 따를 때와 회원 관리에 필요할 때뿐입니다.

Cluey 가 Google API 에서 받은 정보를 사용하고 다른 곳으로 옮기는 것은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 포함해 그 정책을 따릅니다.

3. 운영자의 접근 원칙, 잠근 메모, 사용 통계

운영자의 접근 원칙

서버에 보관된 메모(잠그지 않은 것)는 동기화와 공유를 하려고 서비스가 읽을 수 있는 상태입니다. 운영자가 이 메모를 열어 보는 것은 (1) 사용자의 문의로 도움이 필요할 때, (2) 보안 사고나 신고를 처리할 때, (3) 법에 따른 요청이 있을 때뿐이며, 이유를 적고 열어서 누가 언제 누구의 메모를 열었는지 모두 기록합니다.

잠근 메모

비밀번호로 잠근 메모는 내 PC 에서 암호화(AES-GCM)되어 저장되고, 서버에도 암호화된 채로 올라갑니다. 비밀번호는 어디에도 저장하지 않으므로 운영자를 포함해 누구도 잠근 메모를 읽을 수 없고, 비밀번호를 잊으면 찾아 드릴 수 없습니다(미리 적어 둔 힌트만 보여 드릴 수 있습니다).

사용 통계

로그인한 사용자의 앱은 하루에 한 번 숫자만 서버에 보냅니다.

  • 기능별 사용 횟수
  • 메모, 글자, 폴더, 잠근 메모의 개수
  • 앱 버전
  • 앱 오류의 종류, 위치, 횟수

메모의 제목과 내용, 폴더 이름 같은 내용은 보내지 않습니다. 서비스를 고치고 개선하는 데만 씁니다. 로그인하지 않으면 보내지 않습니다. 이 통계는 가입할 때 동의를 받습니다.

3-1. 메모 보내기

메모 보내기는 Cluey 를 쓰는 사람끼리 메모를 전달하는 고를 수 있는 기능입니다. 사람마다 열쇠 한 쌍(X25519)을 만들어, 공개 열쇠만 서버에 올립니다. 메모를 보낼 때는 받는 사람의 공개 열쇠로 내 PC 에서 잠근 뒤(AES-GCM) 서버에 맡기므로, 서버와 운영자는 보내는 중인 메모의 제목과 내용을 볼 수 없습니다. 푸는 열쇠는 내 PC 에만 있습니다(암호화 보관).

3-2. API 키

API 키는 사용자가 직접 만들어 다른 프로그램(AI 도구, 업무 프로그램 등)에 주는 열쇠입니다. 만들지 않으면 아무 일도 일어나지 않습니다.

  • 키를 가진 프로그램은 그 사용자가 서버에 동기화한 메모를 읽을 수 있습니다. 키를 만들 때 정한 폴더 범위 안의 메모만 볼 수 있고, 'AI에게 숨기기'로 숨긴 폴더와 잠근 메모는 볼 수 없습니다. 읽기와 새 메모 쓰기만 되고, 기존 메모를 고치거나 지울 수는 없습니다.
  • 키는 설정의 API 키에서 언제든 끊을 수 있습니다. 끊으면 바로 쓸 수 없게 됩니다. 기한을 정해 두면 그날 저절로 못 쓰게 됩니다.
  • 키로 한 일(언제, 어떤 일, 찾은 글자나 메모 번호)은 기록에 남습니다. 메모 본문은 적지 않습니다.
  • 키는 만들 때 한 번만 보여 드리고, 서버에는 되돌릴 수 없는 값만 보관합니다. 키가 다른 사람에게 알려지면 그 사람도 같은 범위를 읽을 수 있으니 끊고 새로 만들어 주세요.
  • 키를 가진 프로그램이 읽어 간 내용은 그 프로그램을 만든 쪽이 다루는 것이라 Cluey 가 지울 수 없습니다. 믿을 수 있는 프로그램에만 주세요.

3-3. 공유 폴더

공유 폴더는 서로 친구인 사람과 폴더 하나를 함께 쓰는 기능입니다. 사용자가 폴더를 공유하겠다고 하고 상대가 받아야 시작됩니다.

  • 공유 폴더를 받은 사람은 그 폴더와 아래 폴더의 메모를 볼 수 있고, 고치기 권한이면 메모를 만들고 고치고 지울 수도 있습니다. 보기만 권한이면 읽기만 됩니다. 사람을 넣고 빼고 권한을 바꾸는 것은 폴더 주인만 합니다.
  • 공유 폴더의 메모에는 마지막으로 고친 사람의 닉네임이 보입니다. 폴더를 받은 사람에게는 주인의 닉네임이 보이고, 주인에게는 함께 쓰는 사람의 닉네임이 보입니다. 이메일 주소는 주인에게, 그 사람과 서로 친구일 때만 보입니다.
  • 잠근 메모는 공유 폴더에 둘 수 없습니다.
  • 공유 폴더의 메모도 API 키 3-2번의 대상이 될 수 있습니다. 폴더를 함께 쓰는 각 사람이 자기 키로 읽으며, 각자 'AI에게 숨기기'를 따로 정할 수 있습니다.
  • 서버의 운영자 열람 원칙(3번)은 공유 폴더에도 그대로 적용됩니다.

4. 보관 기간과 지우는 방법

  • 내 PC: 메모는 지울 때까지 남습니다. 프로그램을 지운 뒤 문서\Cluey 폴더를 지우면 모두 사라집니다.
  • 로그인 정보: 설정, 계정에서 로그아웃을 누르면 이 PC 의 로그인 정보를 지웁니다. 다른 PC 로그아웃을 누르면 나머지 PC 의 로그인이 끊깁니다. 90일 동안 쓰지 않은 PC 는 저절로 끊깁니다. 구글 계정의 서드 파티 앱 및 서비스에서 Cluey 를 지워도 됩니다.
  • 서버의 계정과 메모 자료: 설정, 계정에서 탈퇴하면 모든 PC 의 로그인이 끊기고 30일 동안 보관합니다(그 안에 다시 로그인하면 되살아납니다). 30일이 지나면 이름, 닉네임, 이메일, 친구 목록, 친구 요청, 내 차단 목록, 보내고 받은 메모, 1:1 기록, 로그인 정보, 서버에 맞춰 둔 메모와 그림을 모두 지웁니다. 내 PC 의 메모는 지워지지 않습니다.
  • 다만 다른 사람이 나를 차단해 둔 경우, 그 사람의 차단 목록에 있는 내 이메일 주소는 그 사람의 정보라 함께 지워지지 않습니다.
  • 서버 용량은 사람마다 1GB 입니다. 공유 폴더에 둔 메모와 그림, 지운 메모 보관분은 그 폴더 주인의 용량으로 계산하고, 폴더를 함께 쓰는 사람의 용량에는 넣지 않습니다.
  • API 키: 설정에서 끊을 수 있고, 끊은 키는 쓸 수 없습니다. 키 사용 기록은 사람마다 최근 1000건만 남기고 오래된 것부터 지웁니다. 탈퇴하면 키는 바로 끊기고, 30일 뒤 키와 기록을 지웁니다.
  • 공유 폴더에서 지운 메모는 30일 동안 보관하고(주인과 고치기 권한인 사람이 최근 지운 메모에서 되살릴 수 있습니다) 그 뒤 지웁니다. 공유 폴더를 끝내면 받은 사람은 더 볼 수 없고 메모는 주인에게 남습니다. 폴더에서 나가거나 빠진 사람이 쓴 메모는 폴더에 그대로 남고, 그 사람의 PC 에서는 그 폴더가 사라집니다.
  • 공유 폴더 주인이 탈퇴하면, 탈퇴 전에 다른 사람에게 주인을 넘길 수 있습니다(앱이 탈퇴 전에 묻습니다). 넘기지 않으면 30일 보관 기간 동안은 공유 폴더가 그대로 쓰이고, 30일이 지나면 그 사람이 주인인 공유 폴더와 그 안의 메모, 지운 메모 보관분을 지웁니다. 이 폴더를 함께 쓰던 사람은 그 뒤로 볼 수 없으니 필요한 내용은 미리 자기 폴더로 옮겨 두세요.
  • 보낸 메모는 받거나 거절하면 바로, 아니면 30일 뒤 지웁니다. 실시간 연결의 접속 중 여부와 초대는 저장하지 않고, 친구와 함께한 자리의 진행 상태는 끝나면 지웁니다. 메모 보내기 창의 내 보내기 정보 지우기를 누르면 서버의 내 열쇠, 이름, 친구 목록, 친구 요청, 내 차단 목록, 받기 전 메모, 1:1 기록을 지웁니다.
  • 구글 드라이브의 예전 메모 자료: 구글 드라이브 웹, 설정, 앱 관리, Cluey, 숨겨진 앱 데이터 삭제로 지울 수 있습니다.
  • 위 방법 말고 문의 메일로 지워 달라고 요청해도 됩니다.

Summary in English

Cluey is a note-taking app for Windows. Notes are stored on the user's PC. Signing in is optional and uses a Google account only. If the user signs in, Cluey stores the Google email address, the Google profile name (as the real name), a nickname chosen by the user, the time of consent, and login information (PC name, first and last use) on Cluey's server, which runs on Cloudflare (Workers, D1, R2). Signed-in users' notes, folders, templates, places and images are synced to the server so that several PCs can be kept in step and so that sending notes and features used with friends work. Notes that are not locked can be read by the service for those features. The operator opens a user's notes only to answer the user's inquiry, to handle a security incident or report, or to comply with a legal request, with a reason, and every access is logged. Notes locked with a password are encrypted on the PC and stay encrypted on the server; nobody, including the operator, can read them, and passwords cannot be recovered.

Signed-in users' apps send usage statistics once a day, counts only and never content: the number of uses of each feature, the number of notes, characters, folders and locked notes, the app version, and app error types and locations. Signed-out users send nothing. The optional "send a note" feature stores a public key, friend lists and requests, a nickname, block lists, 1:1 records of features used with friends, and notes end-to-end encrypted with the recipient's public key (at most 30 days). Real-time presence and invitations are not stored.

Cluey requests only the openid, email and profile Google scopes. It no longer requests Google Drive access. Users who granted Drive access in an earlier version have their Cluey application data in Drive read once, to migrate it to the server; the Drive copies are only read, never changed or deleted, and users can delete them in Google Drive settings. Google user data is never sold or used for advertising. Cluey's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

API keys are optional and created by the user. A program holding a key can read the user's synced notes within the key's folder scope (never locked notes or folders hidden from AI), the user can revoke a key at any time, and key usage is logged without note text. Shared folders are optional: people the user shares a folder with can see its notes and, if allowed, edit them; locked notes cannot be placed in a shared folder; deleted notes in a shared folder are kept for 30 days; shared folder data counts toward the owner's storage. If the owner deletes the account, shared folders they own are deleted after 30 days unless ownership is transferred first.

Each user has 1 GB of server storage. When a user deletes the account, the account is kept for 30 days (signing in again within that time restores it), then all server data is deleted; notes on the user's PCs are not deleted. Refresh and session tokens on the PC are encrypted with Windows DPAPI. Contact: kyg6135@naver.com.
